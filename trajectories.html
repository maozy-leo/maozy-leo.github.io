CTFE · Quantitative Research Team

Quant Researcher Intern

Working with a quantitative research team under Chow Tai Fook Enterprises (CTFE), gaining practical experience in a professional quantitative research environment. My work includes:

  • Exploring and testing mid- to low-frequency quantitative trading factors.
  • Developing a multilevel stock-classification algorithm with the Leidenalg Python library for dynamic concept-sector discovery and the identification of anomalous stock clusters.
  • Building a Skill + MCP workflow compatible with agents such as Codex that can generate or modify factors from natural-language input. The workflow automates the process from data cleaning and DolphinDB implementation to server-side computation and backtesting. A test sandbox gives the agent execution feedback, improving code reliability and reducing errors in generated DolphinDB programs.
